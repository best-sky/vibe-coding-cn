# 智藏 — 分步实施计划

> 版本：v1.0 | 更新日期：2026-03-01
>
> 原则：每一步要小而具体，每一步必须包含验证测试，先聚焦基础功能。

---

## 总览

| 阶段 | 内容 | 预计耗时 | 产出 |
|:---|:---|:---|:---|
| Step 0 | 环境准备 | 1 小时 | 开发环境就绪 |
| Step 1 | 项目脚手架 + 首页框架 | 2 小时 | 空壳小程序能跑起来 |
| Step 2 | 字数统计工具 | 1 小时 | 第一个完整工具上线 |
| Step 3 | 个人所得税计算器 | 1.5 小时 | 实用计算工具验证 |
| Step 4 | 亲戚关系计算器 | 1.5 小时 | 趣味工具验证 |
| Step 5 | 图片压缩工具 | 2 小时 | Canvas 图片处理验证 |
| Step 6 | AI 证件照制作 | 3 小时 | 核心功能完成 |
| Step 7 | 云开发 + 混元 AI 接入 | 2 小时 | AI 能力跑通 |

## Step 0：环境准备

### 任务清单

1. 下载安装「微信开发者工具」（最新稳定版）
2. 在微信公众平台注册小程序账号（个人主体）
3. 选择服务类目：**工具 → 信息查询**（个人可选）
4. 记录 AppID
5. 在小程序后台申请「AI 小程序成长计划」
6. 开通微信云开发环境（免费额度）
7. 安装 Node.js（≥ 16）和 Git

### 验证标准

- [ ] 微信开发者工具能正常打开
- [ ] 能创建一个空白小程序项目并预览
- [ ] 云开发控制台能正常访问
- [ ] AI 成长计划申请已提交

## Step 1：项目脚手架 + 首页框架

### 任务清单

1. 用微信开发者工具创建项目，选择「JavaScript + 不使用云服务」模板
2. 初始化 npm，安装 TDesign：`npm i tdesign-miniprogram --production`
3. 在微信开发者工具中「构建 npm」
4. 配置 `app.json`：
   - 设置 tabBar（首页 + 我的）
   - 配置分包（packageImage、packageText、packageUtil）
   - 移除 `"style": "v2"`（避免与 TDesign 冲突）
5. 创建首页 `pages/index/`：
   - 顶部搜索栏
   - 分类 Tab（全部 / AI 图片 / AI 文字 / 实用工具）
   - 工具卡片宫格布局（使用 TDesign Grid 组件）
6. 创建「我的」页面 `pages/mine/`（占位，后面填充）
7. 配置全局样式（主题色、字体）

### 验证标准

- [ ] 小程序能正常启动显示首页
- [ ] TDesign 组件正常渲染（Tab、Grid、Card）
- [ ] 首页显示 8 个工具卡片（可点击但跳转空页面）
- [ ] tabBar 切换正常
- [ ] 真机预览正常

## Step 3：个人所得税计算器

### 任务清单

1. 在 `packageUtil/tax-calculator/` 创建页面
2. UI：
   - 计算模式切换（月薪计算 / 年终奖计算）
   - 税前月薪输入框
   - 五险一金输入区域（养老 8%、医疗 2%、失业 0.5%、公积金 5%-12%，支持自定义比例）
   - 专项附加扣除选择（子女教育、继续教育、大病医疗、住房贷款、住房租金、赡养老人、3 岁以下婴幼儿照护）
   - 「一键计算」按钮
   - 结果展示区：应纳税所得额、税率、速算扣除数、个税金额、到手工资
   - 年度汇总表（12 个月逐月累计税额明细）
3. 功能：
   - 2024 年最新税率表（7 级超额累进：3%/10%/20%/25%/30%/35%/45%）
   - 累计预扣法计算个税（按年度累计方式）

## Step 4：亲戚关系计算器

### 任务清单

1. 在 `packageUtil/relative-calc/` 创建页面
2. UI：
   - 关系链输入区域：链式按钮组（爸爸 / 妈妈 / 哥哥 / 弟弟 / 姐姐 / 妹妹 / 儿子 / 女儿 / 丈夫 / 妻子）
   - 已选关系链显示（如：「爸爸 → 妈妈 → 弟弟」）
   - 回退按钮（删除最后一个关系）
   - 清空按钮
   - 结果展示区：称谓（如「舅舅」）+ 对方称呼你（如「外甥/外甥女」）
   - 性别切换（我是男/女，影响对方称呼）
3. 功能：
   - 内置完整的中国亲戚关系映射数据（覆盖 3-4 代常见亲戚）
   - 关系链递归计算：每选一步都实时推导当前称谓
   - 支持父系/母系关系区分（姑 vs 姨、叔 vs 舅）
   - 支持配偶关系引入（如「爸爸的姐姐的丈夫」= 姑父）
   - 处理无法确定的关系（给出最接近的称谓或提示「关系较远」）

## Step 10：宠物 Q 版头像生成

> **技术说明**：微信云开发 `wx.cloud.extend.AI.createImageModel("hunyuan-image")` 仅支持**纯文生图**（Text-to-Image），不支持传入参考图（Image-to-Image）。因此采用「选择宠物类型 + 文字描述特征 + 风格提示词」方案生成 Q 版头像。

### 任务清单

1. 在 `packageImage/pet-avatar/` 创建页面
2. UI：
   - 宠物类型选择（猫咪 / 狗狗 / 兔子 / 仓鼠 / 小鸟 / 其他）
   - 宠物特征描述输入框（如"白色短毛加菲猫"）
   - 风格选择网格（日系 Q 版 / 像素风 / 水彩风 / 赛博朋克 / 毛绒玩具风 / 漫画风）
   - 「生成头像」按钮 + 生成中 loading 状态
   - 结果预览区（生成的 Q 版头像）
   - 保存到相册 / 重新生成按钮
3. 功能：
   - 用户选择宠物类型并填写特征描述
   - `buildPrompt()` 将宠物信息与风格提示词组合为完整 prompt
   - 调用 `generateImage(prompt)` 纯文生图接口
   - 结果图片展示 + 长按保存 + 保存到相册
   - 生成历史本地缓存（最近 5 次）
4. 风格提示词模板存放在 `services/pet-avatar-prompts.js`
5. 依赖 Step 7 的 AI 服务封装

### 验证标准

- [ ] 能选择宠物类型并输入描述
- [ ] 6 种风格均能正常生成
- [ ] 生成时间 < 15 秒，有 loading 反馈
- [ ] 生成结果能保存到相册
- [ ] 重新生成可获得不同结果
- [ ] 真机测试通过

## 执行铁律

```

4. 验证通过 → Git 提交

6. /clear 清理上下文 → 进入下一步
```
